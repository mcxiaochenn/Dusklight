# 导航响应式修复与验收

2026-10-28，基于 main 的 78f5e50。

导航按实际容器宽度切换：不超过 768px 使用菜单，不超过 480px 将主题切换放入菜单。品牌可收缩并省略，搜索、主题和菜单按钮保持 44px 点击区域。主题入口共用一个管理器和模块级事件委托；搜索仍为单一 Svelte 岛。

移动菜单使用原生 dialog 隔离背景；打开聚焦关闭按钮，Tab 首尾循环，Escape 关闭并返回触发按钮。

## 已验证

- 集成候选覆盖 320、360、390、768、1440px，明暗主题及 CSS zoom 1/2，共 20 组。
- 原先 390px + CSS 200% 的页面超宽不再出现；导航边界始终位于视口内。320px + CSS 200% 页面存在 1px 舍入差，导航右边界为 296px，不是导航溢出。
- 移动菜单打开、Shift+Tab 边界和 Escape 返回焦点通过，浏览器未处理异常为 0。
- 导航独立分支类型检查 0 错误、0 警告，保留基线 9 条提示；与类型清理候选集成后 0 提示。

- 最终集成候选标准 pnpm check 为 0 错误、0 警告、0 提示；完整构建 105 页、audit:dist、assets:check 通过。连续换页、主题切换、菜单重复打开无累积事件。

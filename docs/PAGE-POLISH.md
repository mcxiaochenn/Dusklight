# 文章浏览页面

归档、标签／分类索引及详情采用本站字体、主题色和实体表面，不新增侧栏或运行时依赖。

## 行为

- 归档按现有 UTC 日期年份及发布日期倒序排列，支持 ?year=YYYY 与年份锚点。刷新、前进后退重新读取年份，无效年份显示全部。
- 静态 HTML 保留完整列表，无 JavaScript 时可阅读全部文章并通过锚点定位。
- 归档与主题详情共用横向封面列表。图片固定 160×90／移动端 96×54，懒加载；缺失或失败使用现有兜底图。
- 标签／分类卡片展示名称、数量及最近三篇文章；同一篇文章重复标签计一次，同数量按中文名称排序。
- 保留现有路由、草稿过滤、abbrlink、首页卡片与分类评论入口。
